## Variant: B2 — video on the lane header

### Design stance
The row is screenshots-only (one card = one proof); the whole-run video is a ▶ pill on the lane header line — same cinema destination, zero row space.

### Key choices
- Layout: header line gains a `▶ whole run · 24.9s` pill next to the pass/shot counts
- Row rhythm uniform across swap lanes and legacy lanes
- Video presence reduced to metadata + one click

### Trade-offs
- Strong at: cleanest rows; scales to many worlds; header already names the run the video duplicates
- Weak at: video is discoverable only if you read the header; no in-gallery preview frame of the video

### Best for
Stills-primary evidence reading — video as deep-dive, which matches how swap runs are actually verified (per-world frames).
