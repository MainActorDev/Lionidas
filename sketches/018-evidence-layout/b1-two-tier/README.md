## Variant: B1 — two-tier lane

### Design stance
Screenshots are the proof tier; the whole-run video is a subordinated full-width strip below them — chronology under evidence.

### Key choices
- Layout: card row (proofs) + horizontal video strip (chronology) per lane
- The video strip carries run facts inline: duration, swap sequence, size
- Old lanes get the identical two-tier shape (1 shot + strip) — one rhythm for all lanes

### Trade-offs
- Strong at: video stays visible and scannable; the strip can later carry scrubbing/world markers
- Weak at: each lane is taller; with many lanes the strips add vertical noise

### Best for
Treating video as a real artifact people open often — the strip is a persistent invitation.
