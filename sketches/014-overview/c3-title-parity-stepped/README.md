## Variant C3 — title-parity, stepped (C + hierarchy fix, take 2)

### Design stance
Keep the standard page-title row (parity with siblings) and fix hierarchy the classical way: a hard size step plus air.

### Key choices
- Page title row unchanged: `overview · count` 20px — same as every page
- Verdict word bumped 24px → 32px, so the step is 20 → 32 with 48px of air between
- Sub-line stays 13px ash — three distinct tiers, no competition

### Trade-offs
- Strong at: keeps navigation parity AND fixes the contest; one-token change from C
- Weak at: two "big" elements still on screen — relies on spacing, not elimination, for hierarchy

### Best for
Keeping the app's anatomy consistent while letting the verdict win.
