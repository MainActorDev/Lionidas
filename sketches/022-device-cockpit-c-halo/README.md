## Variant: C — Command-halo stance

### Design stance
The most minimal chrome: a command bar up top, quick-action clusters floating beside the bezel, watchers as docked cards below. Fastest path from thought → action.

### Key choices
- Layout: full-bleed stage; halo clusters (device/app/network/location left, session/idle/captures/failures right), docked watcher cards
- A ⌘-style command input for everything ("play case · set location · activate scenario")
- Device switcher as dots top-right; status lives INSIDE the halo tiles, not separate panels
- Watchers dock as cards that can be closed/added

### Trade-offs
- Strong at: speed + focus; the command bar future-proofs "many things from there" (agent commands later?)
- Weak at: least conventional — halo tiles need a hover/tap to expand; discoverability of full controls; dock cards + halo can collide on small viewports

### Best for
Power users who know what they want; a future where typed/agent commands join clickable controls.
