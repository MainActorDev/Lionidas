# 032 B3 — floating glass workspace (canvas split)

## Variant: a3-2's split, softened into a floating glass card with the orbit flow

### Design stance
The panel detaches from the layout — a 24px-radius blurred glass card floating over the canvas with depth shadow — and the stage flow inside becomes the compact ORBIT (done planets + breathing current). The most "out-of-the-box" execution of the split.

### Working interactions
everything from a3-2 (tabs pipeline/artifacts, answer → orbit author ✓ + drafts + pill settles).

### Trade-offs
Strong: distinctive; the run reads as an object you could imagine dragging; keeps full split power. Weak: glass blur costs renders; least house-conventional; floating panel implies draggability it doesn't have (build would either add drag or settle it docked).
