# 032 B2 — workspace-in-chat (tabbed inline section)

## Variant: no side panel at all — the workspace rides IN the thread

### Design stance
One column. The run's machinery arrives as a wide tabbed SECTION inside the agent's message (pipeline ● / drafts 3 / knowledge v3) — horizontal compact stage flow, the question, drafts, and the knowledge page all one tab away. Chat and state scroll together, chronologically.

### Working interactions
tabs switch; answer → question dissolves, author ✓, count 3→5, pill settles, auto-jumps to drafts tab; composer echoes turns.

### Trade-offs
Strong: nothing competes with the thread; the workspace appears exactly when the agent reports it; simplest responsive story. Weak: workspace scrolls away with the thread (must scroll back); wide flows compress on narrow screens.
