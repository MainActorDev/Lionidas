# 032 A3-3 — canvas

## Variant: the agent as ambient presence (freest form)

### Design stance
Maximum departure inside the same skeleton: rail of chat dots instead of a list sidebar; turns anchored by small orbs, no bubbles/boxes at all; the pipeline renders as an ORBIT of stage planets (done = filled, current = breathing ember glow); question floats as an ember-wash speech shape (26/26/26/6 radius); drafts are pills; composer is a pill-island.

### Working interactions
answer → orbit planet ✓ + draft pills appear + header settles; composer enter echoes user turns; rail dots hover/select; new resets.

### Trade-offs
Strong: most "out of the box"; the agent feels alive; memorable. Weak: furthest from Claude reference; orbit metaphor may tire; least information-dense.
