# 032 A3-2 — artifacts split

## Variant: thread + right workspace panel (Claude artifacts panel pattern)

### Design stance
Chat stays lean prose; the run's MACHINERY lives in a right panel — vertical stage flow (knowledge→plan→breakdown→author) with per-stage results, the pending QUESTION, drafts, and the versioned knowledge page (artifacts tab). Claude's artifacts-panel precedent, applied to the pipeline.

### Working interactions
panel tabs (pipeline/artifacts); answer & continue → question dissolves, author node ✓, all-5-drafts, header pill settles; drafts hoverable.

### Trade-offs
Strong: questions unmissable; artifacts/knowledge have a home; chat stays clean. Weak: narrower thread; panel is fixed-cost even for tiny runs.
