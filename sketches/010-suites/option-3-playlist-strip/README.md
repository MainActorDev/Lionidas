## Option 3 — Playlist strip (absorbs plans)

### Stance
Suites are playlists ON home: a tabbed strip where one suite is expanded at a time — and the old
plans strip is ABSORBED (a plan ≈ a one-shot suite; legacy plans import as suites).

### Key choices
- Tabs with micro-rollups (`2✓ 1✗ 1○`), `+ suite` tab; the expanded pane shows members + chips + trends
- Compact member grid (pos · verdict · name · chips), run in the pane header
- Plans absorption kills a parallel concept instead of adding a second one
- **Collision:** home hero → `▶ run all cases`; the strip is the suites surface, no new route

### Trade-offs
+ One concept fewer (plans die into suites); keyboard-switchable tabs; least nav churn
+ The strip keeps the home board as the backdrop (dimmed, still visible)
− Absorbing plans is a migration (import mapping tags→members must be built; T5's plans-reference-suites changes meaning)
− Tab strip caps visible suites (~8-10 before it scrolls); one-pane-at-a-time hides comparisons

### Best for
Teams that mostly re-run remembered groups and want ONE surface for "run stuff" — the boldest
consolidation of the three.
