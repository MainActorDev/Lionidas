## Option 2 — Home row + drawer

### Stance
Suites ride ON the home board: a `suites` row of cards directly under the hero header, each card
runnable; clicking opens an in-place drawer below the row (case grid never navigates away).

### Key choices
- Suite cards carry name + mini rollup + their own `▶ run`
- Drawer = the detail: rollup KPI, ordered members, variant chips + trends, edit/runs links
- The all-cases board stays the page's spine — cards dim while the drawer is open
- **Collision:** home hero → `▶ run all cases`; each suite card has its own run. No new route

### Trade-offs
+ Zero new navigation; suites surface exactly where "run everything" already lives
+ The drawer keeps context (board visible behind)
− Home gets denser as suites grow; drawer height competes with the case grid
− No home for suite-level history/settings beyond the drawer

### Best for
A handful of suites treated as quick-launch groups (the "playlist" mindset) on top of the whole-library board.
