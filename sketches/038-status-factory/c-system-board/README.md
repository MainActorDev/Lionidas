# C — System board

**Stance:** Equal-weight tiles offer a quick systems inventory, with selected details in one separate section below.

- Hierarchy: overall state and observation time → seven system tiles with short signals → selected observations and threshold.
- Interaction: select a tile to update the detail section; mobile scrolls to it on selection. Selected state is textual as well as tonal.
- Strong at: seeing broad subsystem coverage.
- Weak at: on mobile, the default selected detail begins below the initial viewport, so investigation takes more movement; card grid uses more vertical space.
- Best for: glance-first monitoring, less for triage.

The HTML includes a shell approximation of the existing `App.vue`; production keeps the actual shell. Sample values are illustrative, not live telemetry. System count is dynamic; the build-config canary may be absent.
