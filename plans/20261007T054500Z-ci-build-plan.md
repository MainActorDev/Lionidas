# CI build — simulator .ipa from workspace clones (plan)

- Source: brainstorm/20261007T052303Z-ci-build-simulator-ipa.md (Q1=C hybrid transport, Q2 auto-discover, Q3 new Jenkins-style page, sketched first)
- Status: Ready
- Scope: build jobs for registered projects → simulator .ipa in packages/, auto-claimed. OUT: apk, schedulers, GH-hosted runners, the app-repo `build_sim` lane (follow-up).

## Server

1. **Schema**: `builds` table — `id, project_id (FK cascade), number (per project, 1..n), status ('running'|'passed'|'failed'), transport ('repo-lane'|'generic'), scheme, started_at, finished_at, duration_ms computed, log_path, artifact_path, error`. Build numbers monotonic per project.
2. **`server/src/projects/builds.ts`**:
   - `startBuild(db, projectId)` — guards: project exists, workspace exists (else 409 CLONE_FIRST), no running build for the project (409 BUILD_RUNNING).
   - Transport pick: `scripts/build-sim.sh` executable in clone → run it (cwd=clone); else `fastlane/Fastfile` containing `build_sim` → `bundle exec fastlane build_sim`; else generic: `xcodegen generate` if `project.yml` present; scheme via `xcodebuild -list -json` (first non-suffix-Tests scheme); `xcodebuild -scheme S -sdk iphonesimulator -configuration Debug -derivedDataPath <clone>/.derived-data build`; find newest `.app` under `DerivedData/Build/Products/Debug-iphonesimulator/`; `zip -q -r -X <packages>/<project>-<version>-<n>.ipa Payload` (staging dir).
   - Execution: `spawn` (not execFile — long-running), log streamed to `server/artifacts/builds/<id>.log` (append chunks), per-project serial queue (one build per project at a time; different projects may build in parallel), 45-min timeout kill.
   - Success: ipa written → `readIpaIdentity` → if not simulator platform (DTPlatformName), job FAILS with the named reason (guard parity); else `claimPackage(path, project_id)` + finish passed.
   - `listBuilds(db, projectId?)`, `getBuild(db, id)` (with log tail read).
   - Honest log: include the chosen transport + resolved scheme in the first log lines.
3. **Routes** (admin): `POST /api/projects/:id/builds` (start), `GET /api/builds` (all, newest first), `GET /api/builds/:id` (detail+log), `GET /api/builds/:id/log` (full text). Projects page row gains a `build` action in a later commit.
4. **Tests** (`builds.test.ts`, fake toolchain on PATH — fake `sh` runners like the fake-git pattern): repo-lane script chosen when present; generic path runs xcodegen+xcodebuild (shims), staging+zip shim writes a real ipa fixture; success claims the package; wrong-platform artifact fails with named error; BUILD_RUNNING 409; log grows; number increments per project.
